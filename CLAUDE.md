# Сайт класу 6-А

Цим проєктом керує telegram-hub: задачі приходять через `claude -p`, публікацію робить hub після
підтвердження власника.

## Правила
- Мова коментарів, комітів і відповідей — українська.
- Після змін — `git add` + `git commit` з осмисленим повідомленням. **Ніколи `git push`.**
- Не видаляй файли масово, не змінюй структуру без потреби; якщо задача цього вимагає — запроси
  підтвердження (needs_approval), як описано в системному промпті.
- Вкладення від власника лежать поза проєктом (шлях у задачі); копіюй їх у проєкт свідомо.

## Про проєкт
- Сайт класу 6-А Требухівського ліцею: **увесь сайт — один файл `index.html`** (~800 рядків, HTML+CSS+JS
  без збірки). Публікація — GitHub Pages з гілки `main`, автоматично після push.
- Сторінка організована вкладками: «Головне коротко», «Зі зборів», «Оголошення», «Уроки 6-А»
  (тижневий розклад, І/ІІ зміна), «Дзвінки» (розклад дзвінків, поточний режим), «Автобуси» (маршрути,
  підвіз/розвезення), «Гуртки», «Підручники» (електронні), «Заяви й бланки», «Офіційний розклад».
- Файли для завантаження (бланки заяв `.docx`, скани розкладу `.jpg`) — у `files/`; посилання на них у
  `index.html` відносні (`files/…`). Нові вкладення від власника копіюй саме туди.
- Правки робити точково: знайти потрібну вкладку/секцію в `index.html`, змінити лише її; не переформатовувати
  весь файл. Зберігати кодування UTF-8 і закінчення рядків LF.
- Журнал змін на сторінці («Що нового» / «Зі зборів») — при змістовній правці додай рядок: дата + що змінено.
